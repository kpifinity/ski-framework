# v3.3.0 — Tamper-evident evidence, standards-native, implementable from the spec

**Released:** 2026-11-02 · **Specification:** 3.1 ([RFC 0004](../RFCs/0004-spec-3-1-alignment.md))

> **Two deliberate breaks, each with an explicit opt-in or a one-line fix:**
> a flat-format Knowledge Graph now needs `SKI_KG_ALLOW_FLAT=true` (or a
> one-time conversion), and strict sovereignty mode checks more before it
> starts. Existing ledgers upgrade in place. Read
> [Upgrading](#upgrading-from-v320) before you deploy.

## Install

```bash
pip install ski-sdk ski-kg-extractor ski-kg-validator ski-audit-ledger ski-model-deploy ski-schemas
docker pull ghcr.io/kpifinity/ski-model:3.3.0
```

## Highlights

### Strict sovereignty mode, completed (spec §6)
- More startup checks in strict mode: the KG must be anchored, the weight
  hash verified against the served weights, the ledger role unable to rewrite
  rows, TLS on, and a single worker. Each check names its fix.
- A process-wide egress guard with an explicit allowlist (loopback, the ledger,
  the model backend) watches every connection after startup and fails closed.
- `/api/sovereignty` attests more, and `ski_sdk.verify_sovereignty_attestation`
  verifies an attestation offline.

### Ledger format 5: tamper-evident evidence, end to end (spec §7)
- The entry hash also covers tenant, KG version hash, model weight hash and
  schema version, so every §7.1 column is chained.
- Each entry carries an Ed25519 **verdict signature** bound to its position, and
  the public keys sit in an append-only table.
- **Checkpoints:** RFC 6962 Merkle roots signed every `SKI_LEDGER_CHECKPOINT_EVERY`
  entries, optionally time-stamped by an in-boundary RFC 3161 TSA and exportable
  to write-once storage. A forward rewrite of the chain no longer goes unnoticed.
- `audit-ledger verify` checks formats 3, 4 and 5, pinned keys and checkpoints;
  `audit-ledger replay` checks each transcript's hashes and signature.

### Standards-native evidence
- `GET /api/ledger/{n}/evidence`: a **SCITT** signed statement with a **COSE
  Receipt** proving the entry's place in a checkpoint, plus a **TRACE v0.2**
  trust record. A generic COSE verifier checks both.
- **OpenSSF Model Signing** checked at boot (`SKI_MODEL_SIGNATURE`,
  `SKI_MODEL_ORIGINS`).
- A **CycloneDX 1.6 ML-BOM** at `GET /api/mlbom`, and **OSCAL 1.1.3 Assessment
  Results** from `audit-ledger export-oscal`.
- A provisional **ISO/IEC 24970** crosswalk.

### Implementable from the specification
- **Specification 3.1** says what the contracts and test vectors already pin:
  RFC 8785 canonical JSON with its rejections, the full assertion predicate set,
  the optional provenance fields, the meaning of `prompt_template_hash`, and
  ledger storage by content. Vendor names are out of the normative text.
- **One Knowledge Graph shape** with spec §5.1 subject routing: a measurement is
  judged only against the Rules that apply to its subject, and an unrouted
  subject goes to human review. One KG version hash; Alembic retired.
- **Black-box conformance suite** (`conformance/blackbox/`): 50 checks that judge
  any implementation through its HTTP API, its ledger and the test vectors, with
  a scripted LLM, and no reference code. The reference passes all 50 in CI.
- **Quality gates:** strict typing on the v3 core and `audit_ledger`, branch
  coverage, fuzzing of the canonicalizer and the KG loader, and mutation testing
  of the verifier and the risk-tier policy (83.7% measured, gated at 82%).
- **Evals:** 312 golden cases across energy, finance and manufacturing, three
  seeds, Wilson 95% intervals, and a weekly run of two open model families.
  The first real-model report is published as measured: the 1-1.5B models are
  far too weak to be useful, and still no breach was ever cleared.

### Fixed along the way
- A window reading beyond the double range was read as "no samples" by the
  stateful verifier; readings are now handled exactly.
- A malformed flat KG (`"rules": [null]`) crashed the loader; it is now refused
  cleanly (found by the new fuzzer).

## Upgrading from v3.2.0

1. **Ledger:** nothing to do if the runtime connects as the schema owner during
   the upgrade; otherwise apply
   `reference-implementation/src/ledger/migrations/0003_ledger_v5.sql` once as
   the owner. Until then the runtime keeps writing format 4.
2. **Flat KGs:** convert once with `scripts/flat-kg-to-graph.py` and re-sign, or
   set `SKI_KG_ALLOW_FLAT=true` for the transition.
3. **Strict mode:** make sure the new checks pass (anchored KG, weights mounted
   for vLLM via `SKI_MODEL_FILE_PATH`, `ski_ledger_writer`, TLS, one worker).
   `advisory` is unchanged.
4. **Optional:** set `SKI_TSA_URL` to time-stamp checkpoints, and
   `SKI_MODEL_SIGNATURE` / `SKI_MODEL_ORIGINS` to verify a signed model.

Full steps are in [docs/migrations.md](../migrations.md). For every change,
see [CHANGELOG.md](https://github.com/kpifinity/ski-framework/blob/main/CHANGELOG.md).
